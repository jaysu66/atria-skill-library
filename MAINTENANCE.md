# Maintenance policy

Atria Skill Library is an open-source engineering asset maintained on a
best-effort basis. It is part of the broader Atria enterprise Agent workbench
exploration, especially multi-Agent collaboration and organizational context.

- Security and accidental-publication reports receive priority.
- Issues and pull requests are welcome, but no response or release schedule is
  guaranteed.
- Skills may remain stable for long periods and are updated when real usage
  produces a reusable improvement.
- Experimental or provenance-unclear material stays outside the public tree.

This repository is not a hosted service and has no SLA.
