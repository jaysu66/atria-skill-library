# Design OS 参考来源

Design OS 可以使用 Refero 帮助 Agent 在实现前研究真实产品，但开源仓库只提供
接入和使用边界，不重新分发 Refero 内容。

- [`REFERO.md`](REFERO.md)：通过用户自己的官方 Refero MCP 连接进行研究。

## 为什么没有内置 Refero 档案

内部曾生成约 100 MB 的 Refero 文本抽取档案。Refero 当前条款允许用户把研究
洞察用于正常产品设计，但禁止抓取后重新分发、公开为数据集/仓库或用于竞争
产品。因此这份档案保持私有，不进入 Git 历史、Release 或安装包。

如果以后取得 Refero 的明确书面再分发授权，应把授权范围和必要声明单独记录，
经过新一轮发布审查后再决定是否增加可下载数据包。
