# Refero 官方接入

Refero 可作为 Design OS 的可选外部研究源。用户需要使用自己的 Refero 账户、
订阅和官方 MCP 接入；Atria 不提供 Refero 内容镜像、共享凭据或批量导出档案。

官方入口：

- [Refero MCP](https://refero.design/mcp)
- [Refero Terms of Use](https://doc.refero.design/legal/terms-of-use)

## 使用方式

1. 由用户按照 Refero 官方说明完成登录和 MCP 授权。
2. 针对当前页面类型、业务场景或交互问题查询少量相关参考。
3. 比较布局、层级、状态和交互规律，形成当前项目自己的 `DESIGN.md`。
4. 只保留设计结论和必要来源链接；不要把 Refero 内容复制回本 Skill。

## 边界

- 不发布 Refero Token、Cookie、登录态或共享账号。
- 不抓取、批量导出、镜像或重新分发 Refero 内容。
- 不把 Refero 内容做成公开数据集、搜索索引或模型训练/评测材料。
- 不复制第三方截图、Logo、品牌文案和专有代码到交付物。
- 客户和组织内部参考只留在对应项目权限范围内。

如果某个产品级集成需要把 Refero 数据提供给终端用户，应先取得 Refero 的单独
业务方案、订单或书面授权，而不是依赖本 Skill 的说明。
