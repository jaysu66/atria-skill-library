# compass

## 用途

`compass` 是需求与产品方向的最小写作协议，避免 Agent 把实现步骤、工具名和未经确认的假设写成需求。

## 能力

- 用项目根 `COMPASS.md` 描述产品是什么、往哪里走、绝对不碰什么
- 用 `docs/需求/<模块>.md` 描述要什么、不做什么、如何验收和为什么
- 在开发前加载方向与对应模块需求
- 对缺失信息明确标记 `[待确认]`，不擅自脑补

## 使用方式

在开始一个功能前，让 Agent 先读取项目 `COMPASS.md` 和对应需求文件。写新需求时遵循 `SKILL.md` 中的结果约束和可证伪验收格式。

## 边界

它不替代项目状态管理、协作锁、设计规范或代码实现；真实项目的 COMPASS 和需求文件留在项目仓库。

## 来源与许可

来源：Atria 本地 `~/.agents/skills/compass`。当前为私有共享预览，公开前需补充明确许可证。
